## 표시와 번호

- 판정 없음은 `-` 대신 `UNKNOWN`으로 표시한다.
- 두 카메라 모두 UNKNOWN인 사람은 작업자별 판정 표에서 숨기며, SITE 집계에서도 제외한다.
- 숨긴 사람의 내부 추적은 최대 2초간 유지해 짧은 가림 뒤 재연결할 수 있게 한다.
- 현재 판정 가능한 내부 ID 11·12·13은 화면·양쪽 카메라·현재 관측에 person1·person2·person3으로 표시한다.
- 미관측 추적과 양쪽 UNKNOWN인 관측은 앞 번호를 예약하지 않는다.
- 숫자를 줄여도 내부 track_id는 바꾸지 않는다. 현재 SAFE/DANGER와 위험 확인 기록은 표시 번호가 아닌 track_id로 연결한다.
- DANGER LATCH와 현재 SITE SAFE 확인 후 수동 RESET하는 동작은 유지한다.

## 발견한 매칭 문제와 수정

기존에는 가장 가까운 쌍부터 하나씩 연결해 다른 사람의 유일한 후보를 먼저 차지할 수 있었다.
이제 전체 대상에 대해 최대한 많은 사람을 일대일로 연결한 뒤 전체 거리 비용이 가장 작은 조합을 고른다.
외부 패키지를 설치하지 않고 프로젝트 내부의 최적 배정 함수를 사용한다.

이전 프레임 두 개의 이동으로 다음 위치를 예측한다. 유효한 공통 Ground 좌표를 카메라 간 매칭에 먼저 사용한다.
기존처럼 유효 좌표가 멀어도 첫 등장 순서만으로 같은 ID에 강제 결합하지 않는다.
좌표가 없거나 신뢰 불가일 때만 같은 카메라의 영상 위치와 공통 등장 순서를 보조적으로 사용한다.
Ground가 크게 튀어도 영상 박스가 50% 이상 겹치고 기준점 이동이 80px 이내이면 영상 위치로 기존 ID를 이어갈 수 있다.

- 카메라별 검출 목록 순서가 반대여도 동일한 공통 좌표를 같은 ID로 연결.
